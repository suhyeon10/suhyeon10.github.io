# 정보처리기사 실기 — 1개월 속성 계획

- 형식: 필답형 100점 만점 / **60점 이상 합격**
- 전략: **프로그래밍 + SQL이 점수의 절반.** 여기서 안정적으로 득점하고,
  나머지는 약어·개념 암기로 합격선(60)을 넘긴다.
- 주당: 10시간+ (속성)

## 출제 영역 & 비중(체감)
| 영역 | 비중 | 학습 포인트 |
|------|------|------|
| 프로그래밍(C/Java/Python) | ★★★★★ | 코드 실행결과 예측 — 포인터·배열·상속·슬라이싱 |
| SQL / 데이터베이스 | ★★★★ | DDL·DML·DCL, 조인, 정규화, 트랜잭션 |
| 정보보안 | ★★★ | 보안위협, 암호화, 접근통제 |
| 네트워크 | ★★ | OSI 7계층, TCP/IP, 프로토콜 |
| SW 설계·개발 | ★★ | 디자인패턴, UML, 테스트, 개발방법론 |
| 신기술 약어 | ★★ | 단답 암기 (고효율) |
| 운영체제 | ★ | 스케줄링, 페이지교체 |

## 주차 계획 (4주)
### W1 — 프로그래밍 집중
- [ ] C: 포인터/배열/구조체, 연산자, 출력형식
- [ ] Java: 클래스/상속/오버라이딩/인터페이스, 예외
- [ ] Python: 자료형/슬라이싱/딕셔너리/내장함수
- [ ] 코드추적 기출 풀이 → 약점 카드화

### W2 — SQL/DB + 네트워크
- [ ] SQL DDL·DML·DCL, JOIN, 서브쿼리, 집계
- [ ] 정규화(1~BCNF), 트랜잭션/ACID, 키
- [ ] OSI 7계층·TCP/IP, 주요 프로토콜, 서브넷

### W3 — 정보보안 + SW설계·개발 + OS
- [ ] 보안위협(SQL인젝션 등)·암호화(대칭/비대칭/해시)·접근통제
- [ ] 디자인패턴(GoF), UML 다이어그램, 테스트 기법
- [ ] 프로세스/스케줄링, 페이지 교체(FIFO/LRU)

### W4 — 약어 암기 + 모의 + 보강
- [ ] 신기술 약어 집중 암기 (덱 반복)
- [ ] 기출 모의시험 2회 → 점수·약점 리포트
- [ ] 약점만 재카드화 후 반복
